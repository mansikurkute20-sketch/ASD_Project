# Autism Spectrum Disorder (ASD) Screening System Using Machine Learning

## Project Overview
The ASD Screening System is a machine learning-based web application designed to screen the possibility of Autism Spectrum Disorder (ASD) using answers to behavioral questions.

The system collects basic information and responses to screening questions, processes the input, and predicts the screening result using a trained machine learning model.

**Note:** This project is intended for preliminary screening and educational purposes only. It does not provide a medical diagnosis. Please consult a qualified healthcare professional for proper evaluation.

## Objectives
- To develop a web-based ASD screening system.
- To use machine learning for analyzing behavioral responses.
- To provide quick screening results.
- To make the screening process simple and user-friendly.

## Installation and Execution

1. Clone the repository:
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:
```bash
cd ADS_Project
```

3. Install the required libraries:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python app.py
```

5. Open your browser and visit:
```text
http://127.0.0.1:5000
```
